### **Tigshop 介绍**

<p>Tigshop是江西佰商科技（集团）旗下的开源电商软件产品，目前由原LYECS创始人杨老师（老杨）带队，我们致力于打造电商领域真正的100%开源商城系统。
目前旗下产品有：单商户标准版、多商户B2B2C商城系统(JAVA/PHP)、多门店O2O线上线下商城系统(JAVA/PHP)、供应商S2B2C商城系统(JAVA/PHP)、跨境多语言多货币商城系统(JAVA/PHP)、批发商城B2B2B系统(JAVA/PHP)、IM在线客服系统、积分商城系统、分销系统，所有产品均100%开源无任何加密
</p>
<p>
TigShop系统拥有庞大且全面的商城功能体系，而且很多功能模块都实现了企业级的闭环，是真正的企业级商城系统。<br>技术架构采用前后端分离开发，后端JAVA版基于SpringBoot3，PHP版基于TP8，前端基于Vue3、TS、Uniapp、Vite、Nuxt3、Element Plus等最新版本的技术栈<br>
    我们的目标：全力打造企业级电商首选框架，拒绝从零开发
</p>

### **Tigshop 开源项目是否会长期维护**

<p>
Tigshop团队有着14年商城软件研发领域的技术积累，我们会秉持初心，一如既往的维护和完善下去。
</p>

### **Tigshop 开源策略**

1. **开源协议**：Apache-2.0。
2. **单商户标准版免费开源**：我们承诺单商户标准版 100%永久免费开源，无任何加密，您可以直接下载使用。

### **Tigshop 盈利模式**

1. **授权和去版权**：前端页面上会有类似 Poweryed By Tigshop 的版权标识，原则上是不能去掉的，购买授权或去版权即可直接后台设置隐藏
2. **Pro等版本授权**：授权后可获取源代码。
3. **企业授权**：针对有一定规模和需求的企业用户，被授权企业可以不限授权次限制（仅限企业本身使用）。
4. **定制业务**：目前只接比较通用的定制功能或优质项目洽谈，具体详情请关注官网动态。

## 功能清单

#### B2C 单商户

面向品牌方自营、DTC 独立站、私域零售等单主体卖货场景。

- 商品 / 订单 / 会员 / 营销 / 财务 / 装修六大核心模块
- Nuxt3 SSR 独立站，完整 SEO 与商品级 SEO 字段
- PC + H5 + 小程序拖拽式 DIY 装修，多主题色与首页模板
- 会员等级、储值、积分、签到、生日礼、会员权益（Pro）
- 优惠券、秒杀、拼团、砍价、满减满赠、预售（定金尾款）、积分商城（Pro）
- 多级分销、分销中心、推广海报（Pro）
- 微信 / 支付宝 / 花呗分期 / 余额 / 组合支付
- 主流快递、电子面单、运费模板、物流轨迹
- 仅退款 / 退货退款 / 换货、售后工单、评价管理
- 内置 IM 客服（Pro）

---

#### B2B2C 多商户

面向类京东 / 天猫的入驻式多商户平台，支持自营 + 第三方入驻共存。

- 平台 / 商户 / 买家三端独立后台，数据与权限隔离
- 商户自主入驻、平台代录入、资质审核、单商户多店铺
- 商户独立商品、库存、订单、营销、财务、装修
- 商品审核、品牌审核、违规下架
- 按店铺 / 品类差异化服务费，T+N 自动结算与提现
- 跨店自动拆单，商户独立运费模板
- 统一会员池，全域积分 / 储值，店铺独立会员标签
- 店铺级 RBAC 员工与角色权限
- 拼团、秒杀、优惠券、满减、分销、直播带货等 30+ 营销工具
- 内置 IM 客服（平台 / 商户独立会话池）

---

#### O2O 多门店

面向连锁零售、本地生活、多门店餐饮等线上线下一体化场景。

- 单店 / 连锁直营 / 加盟 / 多商户入驻，总部 + 门店多级管理
- 会员 / 库存 / 订单 / 营销 / 财务五维实时同步
- 内置 POS：扫码、现金、储值、积分、优惠券、组合支付、挂单交班
- 门店独立库存、共享库存、区域库存池、门店间调拨
- 到店自提、同城配送、预约到店 / 上门、快递发货
- 自提点管理、LBS 附近门店、自动派单、配送范围与阶梯运费
- 对接达达、顺丰同城、美团跑腿、UU、闪送、蜂鸟即配
- 社区团购、团长返佣、自提点分润
- 门店专属营销，总部统管 + 门店分权
- 可组合 S2B2C 供应商模式（S2B2B2C）

---

#### 跨境多语言

面向品牌出海、海外独立站、跨境 B2B / B2B2C / S2B2C 场景。

- 15+ 内置语言（含阿拉伯语 RTL），可扩展至 100+ 语言
- 30+ 国际货币，汇率自动同步，商品多语言详情与 SEO
- 火山翻译一键 / 批量翻译（商品文案、图片文字）
- PayPal、Stripe、YaBandPay、Antom、Xendit 等跨境支付
- 国内微信 / 支付宝、对公转账、COD
- B2B 账期（月结 / 季结）、授信额度、定金预售
- DHL / FedEx / UPS、4PX / 燕文 / 万邦等国际物流
- 跨境运费模板、物流轨迹、按地区税费配置
- GDPR：Cookie 同意、数据导出与删除
- 多语言 hreflang、Nuxt3 SSR 利于 Google / Bing SEO
- 支持独立站 D2C、多站点、多商户跨境平台、B2B 批发、S2B2C 一件代发

---

#### S2B2C 供应商

面向供应链平台、品牌分销、一件代发、工厂赋能小 B 店铺场景。

- 供应商独立后台：商品、订单、库存、发货、售后、结算
- 一件代发：店铺铺货 → 下单自动拆单 → 供应商发货
- 批发采购、预售、区域代理、集采分销
- S2B2B2C：供应商 + 多店铺 / 多商户 + 消费者
- 订单 / 库存 / 物流 / 售后 / 财务五维协同
- 按店铺供货价、类目差异化费率、平台抽佣自动结算
- 店铺在控价区间内自主定价
- 业务员 / 推广员体系、推广素材与绩效结算
- 供应商入驻审核、商品审核、等级管理
- 拼团、秒杀、优惠券、满减、账期、积分商城等营销工具
- 内置 IM 客服（平台 / 店铺 / 供应商隔离）

---

#### B2B 企业批发

面向工业品、建材、食品原料、渠道分销等企业采购批发场景。

- 独立批发商身份体系，批发商类型分级（普通 / VIP / 区域代理等）
- 入驻审核、后台开通、招商链接 / 二维码 / 海报分享
- 企业实名认证，未登录 / 未认证隐藏价格
- 统一批发价、按类型差异化价、数量阶梯价
- 起批量、倍数购买（如整箱采购）
- 在线询价、多轮议价、询价转订单
- 多规格 SKU 批量加购矩阵，一键提交
- 对公线下汇款、订单识别码、凭证上传
- 月结 / 季结账期、授信额度、买家端自助账期下单与查账
- 定金预售、余额 / 在线支付
- 运费模板、主流快递、电子面单、批量发货、分批发货
- 可组合 B2B2C 多商户、S2B2C 供应链
